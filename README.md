# NÉVOA CAFÉ ☕

Site-conceito premium desenvolvido para o portfólio da **Flowexp Tech**.

## Conceito

A Névoa Café transforma o café em uma pausa sensorial: luz quente, formas orgânicas, tipografia acolhedora e uma xícara animada como protagonista da experiência.

## Tecnologias

- React 19
- TypeScript
- Vite
- Framer Motion
- Lucide React
- CSS responsivo e animações otimizadas

## Executar localmente

```bash
npm install
npm run dev
```

## Gerar versão de produção

```bash
npm run build
npm run preview
```

## Conteúdo

- Hero interativo com xícara criada em CSS
- História da marca
- Cafés especiais
- Cardápio demonstrativo
- Experiência do espaço
- Depoimento
- Localização e horários
- Menu responsivo para dispositivos móveis
- Suporte a `prefers-reduced-motion`
